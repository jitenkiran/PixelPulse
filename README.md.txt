# PicSphere

PicSphere is a lightweight, responsive web application designed to help users search and discover images effortlessly.

## Key Features & Design Decisions

1. **Category Quick-Pick Chips:** Added clickable category buttons below the search input so users can explore popular themes with a single interaction.
2. **Status Placeholder:** Included a dedicated `#result-count` element to give feedback on total results found once the search function is wired in Part 2.
3. **Teal & Dark Slate Palette:** Selected a dark slate background (`#0f172a`) paired with teal highlights (`#0d9488`) for a modern aesthetic that prevents eye strain.
